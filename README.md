# AI Workflow Builder

A modern node-based AI Workflow Builder built with React Flow and FastAPI.

Users can visually create AI pipelines by dragging and connecting workflow nodes while validating the graph structure through a backend DAG validator.

---

## Features

✅ Drag-and-drop workflow editor

✅ Interactive node connections

✅ Dynamic Text Node auto-resizing

✅ Automatic variable detection

✅ Input, Output, LLM, Text, API, Database, Email, Image and Condition nodes

✅ DAG (Directed Acyclic Graph) validation

✅ Responsive premium UI
